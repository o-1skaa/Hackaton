# Smart Caspian Transit

Демонстрационный сайт логистики: React + TypeScript + Vite, FastAPI, Leaflet.
Все грузы, задержки, причины, ETA, расстояния и выбросы демонстрационные.

## Запуск

Нужны Python 3.10+ и Node.js 22.18+ с npm. Остановите старый сервер (Ctrl+C),
в терминале VS Code из корня проекта выполните:

```sh
git pull --ff-only origin main
python start.py
```

Скрипт установит зависимости, пересоберёт сайт и запустит сервер.
Откройте http://127.0.0.1:8000 и обновите страницу Ctrl+F5.
На Linux/macOS при необходимости используйте `python3 start.py`.
Порт 8000 должен быть свободен.

Никакие ключи ИИ не нужны. Старые настройки Gemini / GigaChat в `.env` игнорируются.
Для проверки документов используется `DEMO_API_KEY=demo-local-key` (необязательная
настройка в `backend/.env`; такое же значение по умолчанию).

## Что работает

- Мониторинг четырёх грузов: поиск, фильтр, этапы, ETA и документы.
- Сценарии задержек: случайно выбирается связанная пара «число + причина».
- 7 вариантов: 0 ч — по расписанию, 1,5 ч — очередь погрузки, 3 ч — документы,
  4,5 ч — подача состава, 6 ч — ветер, 8 ч — терминал, 12 ч — досмотр.
- Каждый запрос выбирает сценарий заново; повторения допустимы. ИИ, обучения,
  внешних запросов для задержки и анализа погодных сводок нет.
- Задержка обновляет ETA только выбранного маршрута и попадает в журнал.
- Интерактивная карта в мониторинге и сценариях: перемещение мышью/пальцем,
  масштаб +/−, выбор кнопкой или кликом по линии, всплывающие сведения о точках.
- Основной путь через Махачкалу выделен бирюзовым, альтернативный через Баку —
  оранжевым. Выбранный маршрут выделяется сплошной линией; кнопка «Показать оба»
  возвращает обзор. Выбор синхронизирован с формой генерации задержки.
- Leaflet поставляется вместе с сайтом. Подложка OpenStreetMap требует интернета,
  ключа не требует. При её недоступности остаются линии и переключение.
  Геометрия схематичная, без дорожного роутинга или GPS-слежения.
- Сводки из `backend/data/source_observations.json` остаются справочными:
  новые при запуске сервера, стабильные до перезапуска. На задержку не влияют.
- Проверка типов invoice и packing_list; отправляются только имена и типы файлов.

Состояние хранится в памяти и сбрасывается после остановки сервера.

## Разработка

После первого запуска в `backend/`:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

На Linux/macOS: `.venv/bin/python -m uvicorn app.main:app --reload`.
Во втором терминале, в `frontend/`: `npm ci`, затем `npm run dev`.
Откройте http://localhost:5173. Vite проксирует API на порт 8000.

## Проверки

В `frontend/`: `npm run build`, `npm run lint`, `npm test`.
В `backend/`: `python -m pip install -r requirements-dev.txt`, `python -m pytest -q`.
Контракт: [docs/api-contract.md](docs/api-contract.md). Swagger: http://127.0.0.1:8000/docs.
