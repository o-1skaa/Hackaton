# Smart Caspian Transit

Учебный логистический MVP: React, TypeScript, Vite, FastAPI и Leaflet.
История и исходные сводки синтетические. Геометрия, расписание и коэффициенты выбросов модельные.

## Запуск после обновления

Остановите старый сервер (Ctrl+C). В терминале VS Code из корня проекта:

```sh
git pull --ff-only origin main
python start.py
```

Нужны Python 3.10+ и Node.js 22.18+. Скрипт установит зависимости, соберёт интерфейс и запустит API.
Откройте http://127.0.0.1:8000 и нажмите Ctrl+F5. На Linux/macOS можно использовать `python3`.
Ключи ИИ не нужны. Для проверки документов: `DEMO_API_KEY=demo-local-key` в `backend/.env`.

## Реализовано

- Поиск и фильтр отправок, этапы, прогноз, маршруты и журнал.
- Добавление отправки: название, масса в тоннах, время отправления, погода (0–5), загрузка порта, опоздание поезда, ветер и волны. Направление фиксировано: Астрахань — Бендер-Аббас. Начальный статус — «Ожидает».
- Добавленные отправки и их условия сохраняются в `backend/data/.runtime/shipments.sqlite3`. Прогнозы, проверки документов и журнал пока хранятся в памяти. Не удаляйте `.runtime`, если хотите сохранить отправки.
- Встроенные четыре отправки получают новую синтетическую сводку при запуске. Для добавленных отправок используются введённые условия.
- Прогноз обработки порта/терминала: средняя задержка 8 ближайших наблюдений. Признаки — погода / 5 и загрузка порта / 100, евклидово расстояние. Первые 160 строк history.csv — обучение, последние 40 — проверка. Тестовые строки не участвуют в прогнозе или выборе числа соседей.
- MAE на тестовых данных: прогноз 0,506 ч, постоянный прогноз среднего обучающей части 1,278 ч. Средний прогноз 2,255 ч. Это ошибка обработки терминала на синтетических данных, не ошибка полного ETA. История без дат, поэтому разбиение по строкам не является временной проверкой.
- Погода и загрузка порта влияют на прогноз. Опоздание поезда влияет на стыковку. Ветер и волны справочные: в истории их нет.
- Основной маршрут: ж/д до Махачкалы, паром до Энзели, авто до Бендер-Аббаса. Поезд по плану прибывает через 12 ч, подготовка занимает 1 ч плюс прогноз обработки порта. Паром отправляется через 14 ч, следующие рейсы каждые 24 ч. Ровно к отправлению успеть можно. Пропущенный рейс сдвигает ETA на целое число суток.
- Альтернатива: ж/д через Махачкалу до Баку (20 ч), далее авто через Астару (50 ч). ETA учитывает опоздание поезда и прогноз обработки терминала, парома нет.
- Рекомендация: минимальный ETA, при равенстве меньший CO₂e. До расчёта портовая задержка равна нулю; для честного сравнения рассчитайте оба маршрута.
- Карта: перемещение, масштаб, выбор линии, остановки на русском. Подложка CARTO без подписей требует интернета. При недоступности остаются линии и русские остановки.
- Расстояние каждого участка считается по показанной ломаной на сфере (радиус 6371 км). Это схематичная длина, не фактический дорожный километраж. CO₂e участка = км × масса × коэффициент: ж/д 0,022, паром 0,016, авто 0,08 кг/т·км. Коэффициенты — учебные допущения, не сертифицированные значения. Длительности участков также заданы как допущения.
- Проверка наличия типов invoice и packing_list. Содержимое файлов не анализируется.

## Проверки и репетиция

```sh
cd backend
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

В `frontend/`: `npm ci`, `npm test`, `npm run lint`, `npm run build`.
Сценарий показа и ожидаемые результаты: [docs/demo.md](docs/demo.md).
API: [docs/api-contract.md](docs/api-contract.md), Swagger: http://127.0.0.1:8000/docs.

Для разработки: в `backend/` запустить `python -m uvicorn app.main:app --reload`,
в `frontend/` — `npm run dev`. Vite проксирует запросы на порт 8000.
