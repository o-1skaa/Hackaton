# Smart Caspian Transit

Демонстрационный MVP для кейса №2 IV Каспийского цифрового форума 2026.
React + TypeScript + Vite и FastAPI в одном репозитории.
Все данные синтетические, реальных таможенных, погодных и GPS-интеграций нет.

## Открыть готовый сайт с бэкендом

Нужны Python 3.10+ и Node.js 22.12+ с npm. В терминале VS Code из корня:

```sh
git pull origin main
python start.py
```

На macOS/Linux, если `python` отсутствует: `python3 start.py`.
Скрипт создаёт `backend/.venv`, устанавливает зависимости Python и npm,
собирает фронтенд и запускает единый сервер.
Откройте **http://127.0.0.1:8000**. Остановка: Ctrl+C.
Первый запуск требует интернета. Порт 8000 должен быть свободен.
После изменений UI снова запустите скрипт для пересборки.

## Интерфейс

- Поиск и фильтрация перевозок, карточка и этапы доставки.
- Прогноз задержки и риска с ручными погодой и загрузкой порта.
- Сравнение основного и альтернативного маршрутов: ETA, расстояние, CO₂e.
- Проверка комплектности invoice / packing_list, поиск результата по ID.
- Журнал событий, обновление данных, состояния загрузки и ошибок.

Сайт обращается к настоящим API текущего бэкенда, без подмены данных в браузере.
В проверке документов отправляются только типы и имена файлов, содержимое не загружается.
Локальный демонстрационный ключ: `demo-local-key`; если в `backend/.env` задан
другой `DEMO_API_KEY`, введите его в поле раздела «Документы».
Ключ демонстрационный, это не система авторизации для production.
Состояние прогнозов, проверок и событий хранится в памяти и сбрасывается после перезапуска.

## Разработка: два терминала

Бэкенд из `backend/` (после создания окружения командой выше):

Windows PowerShell:
```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

macOS/Linux:
```sh
.venv/bin/python -m uvicorn app.main:app --reload
```

Фронтенд из `frontend/`:
```sh
npm ci
npm run dev
```

Откройте http://localhost:5173. Vite проксирует `/api` и `/health` в бэкенд.
Для другого адреса API используйте `frontend/.env` по `.env.example`;
при работе на разных origins понадобится соответствующий CORS на сервере.

## Проверки

```sh
cd frontend
npm ci
npm run build
npm run lint
```

Из `backend/`, с Python своего окружения:
```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

## Структура

- `frontend/src/` — интерфейс и типизированный API-клиент.
- `start.py` — совместный запуск сайта и API.
- `backend/app/main.py` — FastAPI, демо-проверки, события и раздача собранного сайта.
- `backend/app/schemas.py` — авторитетные модели запросов и ответов.
- `backend/app/services/` — прогноз и выбор маршрута.
- `backend/data/` — четыре синтетических груза и история задержек.
- `backend/tests/` — API, алгоритмы и интеграция сайта.
- `docs/api-contract.md` — API-контракт; Swagger: http://127.0.0.1:8000/docs.

Если фронтенд ещё не собран, `/` возвращает инструкцию с кодом 503; API доступен отдельно.
Подробности алгоритмов: [backend/README.md](backend/README.md).
