# Backend Smart Caspian Transit

FastAPI, Python 3.10+. Запуск и разработка: [общий README](../README.md).

`app/services/prediction.py` выбирает случайный сценарий из `SCENARIOS`.
Каждый сценарий содержит ID, задержку в часах и связанную причину.
Сводки, история и переданный груз не участвуют в выборе. Внешних запросов нет.
`risk`: low <2 ч, medium <4 ч, high >=4 ч.

`POST /api/predict` обновляет задержку только выбранного маршрута,
последнюю задержку груза и журнал. ETA = базовая длительность + последняя
задержка этого маршрута. Выбор маршрута на карте сам по себе ETA не меняет.

`app/services/routing.py` возвращает схематичные точки [широта, долгота]
для карты, базовые ETA 72/70 ч и демонстрационные расстояния и CO₂e.

Сводки при старте выбираются из файлов и служат справочной информацией.
Проверка документов требует X-API-Key: demo-local-key (или DEMO_API_KEY из .env).
Это проверка комплектности типов документов, файлы не загружаются.
Состояние в памяти сбрасывается при перезапуске.

Контракт: [docs/api-contract.md](../docs/api-contract.md).
Тесты: `python -m pip install -r requirements-dev.txt`, затем `python -m pytest -q`.
