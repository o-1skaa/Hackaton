# Интерфейс логиста

React + TypeScript + Vite. Node.js 22.18+ (или 24+) и npm; Python 3.10+ для backend.

## Обновить и открыть сайт вместе с API

В терминале VS Code из корня репозитория остановите старый сервер (Ctrl+C), затем:

```powershell
git pull --ff-only origin main
python start.py
```

Откройте http://127.0.0.1:8000. Скрипт устанавливает зависимости, пересобирает
фронтенд и запускает backend, раздающий сайт. Обновите страницу через Ctrl+F5.
Если Git сообщает о локальных изменениях, сначала сохраните их коммитом или
`git stash push -u`, затем повторите pull. При необходимости верните stash через
`git stash pop` и разрешите конфликты. Не удаляйте локальную работу через reset.

Если порт 8000 занят, остановите прежний сервер в его терминале. Не запускайте
два экземпляра одновременно. После изменений фронтенда единый сервер нужно
остановить и запустить через `python start.py` заново для пересборки.

## Режим разработки: два терминала

После первого совместного запуска, из корня репозитория:

Терминал 1 (Windows PowerShell):

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

Терминал 2:

```powershell
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173. Vite проксирует `/api`, `/health` и `/openapi.json`
в http://127.0.0.1:8000. При `ECONNREFUSED` сначала запустите backend в терминале 1.
Для отдельного API можно задать `VITE_API_URL` в `.env` и перезапустить Vite.

## Интерфейс

- Мониторинг: грузы, этапы, ETA, интерактивная карта и сравнение маршрутов.
- Прогноз: похожая история, условия, ошибка на отложенной части и стыковка.
- Источники: сводки из файлов или введённые оператором условия. Погода и порт влияют на прогноз, поезд — на стыковку.
- Добавление отправок: параметры груза и текущие условия, сохранение в SQLite.
- Документы и журнал: комплектность документов и события груза.

Карта использует Leaflet 1.9.4 и подложку CARTO без подписей. Остановки подписаны по-русски.
Кнопки и клики по линиям синхронизируют выбор с формой прогноза.
Поддерживаются перетаскивание, масштаб кнопками и всплывающие сведения о точках.
Линии маршрутов схематичные; дорожного роутинга и GPS нет.
Для подложки нужен интернет. При ошибке загрузки отображается уведомление.

ИИ и его ключи не используются. Подробнее: [общий README](../README.md).
